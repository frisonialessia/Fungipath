# Imágenes de la landing

Coloca aquí los PNG (preferible fondo transparente) de especímenes botánicos:
hongos, musgo, ramas, líquenes, hojas. Se usan como acentos editoriales en la
landing (hero y secciones). Nombres sugeridos:

  hero-mushroom.png   ·  specimen-moss.png   ·  specimen-branch.png
  specimen-lichen.png ·  specimen-leaf.png   ·  texture-paper.jpg

Si una imagen no existe, la landing usa su fallback (ilustración SVG) sin romperse.
